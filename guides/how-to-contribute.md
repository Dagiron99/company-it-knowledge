# Как добавить информацию

## Вариант 1: изменить существующую сущность

1. Найдите файл по навигации или стабильному ID.
2. Исправьте metadata и основной текст, сохраняя ссылки по ID.
3. Запустите `python scripts/validate_catalog.py`.
4. Сделайте commit и откройте merge request.

## Вариант 2: создать сущность по шаблону

1. Выберите файл в каталоге [`templates`](../templates/system.md).
2. Скопируйте его в соответствующий раздел и замените все подсказки.
3. Добавьте страницу в `toc.yaml` и индекс раздела.
4. Запустите `python scripts/validate_catalog.py` и `python scripts/build_ai_index.py`.
5. Сделайте commit и откройте merge request с владельцем в reviewers.

## Вариант 3: передать сырой материал

1. Положите старый Markdown, текст или заметку в [`inbox`](../inbox/README.md).
2. Создайте issue или merge request и укажите предполагаемого владельца.
3. Владелец каталога или будущий AI-процесс выделит сущности и связи.

Материал из inbox не является доверенным до human review и merge в структурированный раздел.

## Чек-лист review

- ID стабилен и записан в kebab-case.
- Все связи используют ID, а не отображаемые имена.
- Указаны Source of Truth, владелец, ограничения и реальные вопросы пользователей.
- Нет секретов, production credentials и реальных внутренних адресов.
- Валидация, AI-экспорт и сборка документации проходят успешно.
