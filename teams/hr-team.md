# HR-команда

{% note info %}

Демонстрационный бизнес-владелец кадровых данных сотрудников и правил их использования.

{% endnote %}

## Паспорт

| Факт | Ответ |
| --- | --- |
| Роль | Определяет правила ведения и допустимого использования кадровых данных. |
| Владеет | [Сотрудник](../data/employee.md) и [1С ЗУП](../systems/1c-zup.md). |
| Согласует | Состав полей и цели доступа к персональным данным. |
| Техническая выдача | [Отдел автоматизации](automation-team.md) |
| Канал обращения | Демонстрационный запрос «Доступ к кадровым данным» в service desk. |

## Связи и поток данных

HR-команда определяет данные в [1С ЗУП](../systems/1c-zup.md), которые безопасно предоставляет [Employee API](../services/employee-api.md).

## Частые вопросы

**Кто согласует доступ к ФИО и подразделению?** HR-команда; техническую выдачу выполняет отдел автоматизации.

{% cut "Ограничения и эксплуатация" %}

Реальные контакты в MVP отсутствуют. Для персональных данных доступ выдаётся только под подтверждённую цель и необходимый состав полей.

{% endcut %}
