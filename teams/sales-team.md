# Команда продаж

{% note info %}

Демонстрационный бизнес-владелец процесса продаж и данных о сделках в CRM.

{% endnote %}

## Паспорт

| Факт | Ответ |
| --- | --- |
| Роль | Владелец CRM-процесса и семантики данных о сделках. |
| Владеет | [Сделка](../data/deal.md) в [Bitrix24](../systems/bitrix24.md). |
| Определяет | Этапы воронки, обязательные поля и правила доступа. |
| Технический владелец | [Отдел автоматизации](automation-team.md) |
| Канал обращения | Демонстрационный запрос «CRM и продажи» в service desk. |

## Связи и поток данных

Команда определяет бизнес-правила для [сделок](../data/deal.md); их Source of Truth — [Bitrix24](../systems/bitrix24.md).

## Частые вопросы

**Кто согласует доступ к сделкам?** Команда продаж совместно с техническим владельцем Bitrix24.

{% cut "Ограничения и эксплуатация" %}

Реальные контакты не публикуются. Способ программного получения сделок пока не задокументирован и не должен угадываться.

{% endcut %}
