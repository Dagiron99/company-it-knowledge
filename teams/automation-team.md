# Отдел автоматизации

{% note info %}

Демонстрационная команда разработки и поддержки внутренних API, интеграций и каталога знаний.

{% endnote %}

## Паспорт

| Факт | Ответ |
| --- | --- |
| Роль | Технический владелец API, интеграций и технической части отдельных систем. |
| Основные объекты | [Employee API](../services/employee-api.md), [интеграция ЗУП → Bitrix24](../integrations/zup-to-bitrix.md). |
| Системы | Техническая часть Bitrix24 и Active Directory. |
| Канал обращения | Демонстрационная очередь «IT Automation» в service desk. |
| Эскалация | Система, окружение, время, correlation ID и наблюдаемое поведение. |

## Связи и поток данных

Команда поддерживает путь [1С ЗУП](../systems/1c-zup.md) → [Employee API](../services/employee-api.md) и синхронизацию кадровой копии в [Bitrix24](../systems/bitrix24.md).

## Частые вопросы

**Кто выдаёт доступ к Employee API?** Отдел автоматизации согласует техническую часть после подтверждения владельца данных.

{% cut "Эксплуатация и эскалация" %}

Для инцидента приложите систему, окружение, время, correlation ID и наблюдаемое поведение. Реальный адрес или URL намеренно не указан; персональные контакты не являются стабильными идентификаторами каталога.

{% endcut %}
