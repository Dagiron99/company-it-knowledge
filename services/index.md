# Сервисы

Здесь находятся поддерживаемые программные интерфейсы. Если сервиса нет в каталоге, его endpoint и способ авторизации считаются незадокументированными.

| Сервис | Предоставляет | Владелец | Доступ |
| --- | --- | --- | --- |
| [Employee API](employee-api.md) | Разрешённую часть данных сотрудника | [Отдел автоматизации](../teams/automation-team.md) | REST, service token, по [инструкции](../guides/how-to-get-access.md) |
Сервисы — поддерживаемые интерфейсы получения данных. Здесь указаны протокол, авторизация, окружения, владелец и ограничения.

- [Employee API](employee-api.md) — рекомендуемый API для чтения данных сотрудников.
