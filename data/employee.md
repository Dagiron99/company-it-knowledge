# Сотрудник

## Что представляет собой сущность

Сотрудник — работник компании с устойчивым `employee_id`. Сущность объединяет ФИО, должность, подразделение, руководителя и статус занятости.

## Source of Truth

[1С ЗУП](../systems/1c-zup.md) — Source of Truth для кадровых данных сотрудника. Bitrix24 и Active Directory содержат только производные копии отдельных атрибутов.

## Доступные поля

- `employee_id` — стабильный идентификатор;
- `full_name` — ФИО;
- `department` — подразделение или отдел;
- `manager_id` — руководитель или начальник;
- `position` — должность;
- `employment_status` — кадровый статус.

## Рекомендуемый способ получения

Используйте [Employee API](../services/employee-api.md). Он возвращает разрешённое подмножество данных из 1С ЗУП и скрывает детали подключения к кадровой системе.

## Как получать не рекомендуется

Не читайте кадровые сведения напрямую из Bitrix24, Active Directory, таблиц ручной выгрузки или базы 1С. Такие копии могут быть неполными или устаревшими.

## Ограничения

Данные имеют категорию `personal_data`. Доступ выдаётся по принципу минимальных привилегий; зарплата и документы сотрудника в Employee API не публикуются.

## Связанные системы и сервисы

Данные хранятся в 1С ЗУП, доступны через Employee API и частично передаются в Bitrix24 по [интеграции](../integrations/zup-to-bitrix.md).

## Частые вопросы

**Где получить руководителя, начальника или подразделение сотрудника?** В Employee API по `employee_id`.

**Что делать, если API не содержит нужного поля?** Обратиться к владельцу и считать поле незадокументированным до обновления каталога.
