# Active Directory

## Что это

Active Directory — демонстрационный каталог корпоративных учётных записей и групп доступа.

## Для чего используется

Система используется для аутентификации, назначения групп и сопоставления технического логина с сотрудником.

## Какие данные содержит

Каталог содержит логин, технический идентификатор, статус учётной записи и членство в группах. ФИО и подразделение могут присутствовать как копия.

## Source of Truth

Active Directory является источником истины для учётной записи и групп доступа, но не для кадровой сущности [«Сотрудник»](../data/employee.md). Кадровые сведения необходимо получать из 1С ЗУП через Employee API.

## Как получить данные

Способ программного чтения каталога в MVP не задокументирован. Для доступа используйте [общую инструкцию](../guides/how-to-get-access.md).

## Владелец

Владелец — [отдел автоматизации](../teams/automation-team.md).

## Связанные системы

Сотрудники сопоставляются с [1С ЗУП](1c-zup.md) и [Bitrix24](bitrix24.md) по стабильному идентификатору.

## Ограничения

Группы доступа не описывают кадровое подчинение. Нельзя определять руководителя сотрудника по структуре групп.

## Частые вопросы

**Где получить руководителя?** Не в Active Directory; используйте Employee API.
