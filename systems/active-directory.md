# Active Directory

{% note info %}

Демонстрационный каталог корпоративных учётных записей, технических идентификаторов и групп доступа.

{% endnote %}

## Паспорт

| Факт | Ответ |
| --- | --- |
| Назначение | Аутентификация, группы доступа и сопоставление технического логина с сотрудником. |
| Источник истины | Для учётной записи и групп доступа. |
| Не является Source of Truth | Для [сотрудника](../data/employee.md), подразделения и руководителя. |
| Владелец | [Отдел автоматизации](../teams/automation-team.md) |
| Рекомендуемый доступ | Программный способ чтения в MVP не задокументирован; используйте [инструкцию](../guides/how-to-get-access.md). |

## Связи и поток данных

Учётные записи сотрудников сопоставляются со стабильными идентификаторами в [1С ЗУП](1c-zup.md) и [Bitrix24](bitrix24.md). Кадровые данные следует получать из 1С ЗУП через [Employee API](../services/employee-api.md).

## Частые вопросы

**Где получить руководителя?** Не в Active Directory; используйте Employee API.

{% cut "Доступ и ограничения" %}

Группы доступа не описывают кадровое подчинение. Нельзя определять руководителя сотрудника по структуре групп.

{% endcut %}

{% cut "Эксплуатация" %}

За техническую поддержку каталога учётных записей отвечает [отдел автоматизации](../teams/automation-team.md). Реальные адреса, группы и учётные данные в MVP не публикуются.

{% endcut %}
