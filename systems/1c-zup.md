# 1С Зарплата и управление персоналом

## Что это

1С ЗУП — демонстрационная кадровая система компании. Здесь кадровые специалисты ведут сведения о работниках, назначениях и организационной структуре.

## Для чего используется

Система хранит утверждённые кадровые данные: табельный ID, ФИО, должность, подразделение, непосредственного руководителя и статус занятости.

## Какие данные содержит

Основная сущность — [сотрудник](../data/employee.md).

## Source of Truth

1С ЗУП является единственным Source of Truth в MVP для сотрудника, работника, руководителя, начальника, подразделения, отдела, должности и кадрового статуса.

## Как получить данные

Интеграциям следует использовать [Employee API](../services/employee-api.md). Прямое чтение базы 1С, выгрузки из интерфейса и чтение копии в Bitrix24 не рекомендуются.

## Владелец

Бизнес-владелец — [HR-команда](../teams/hr-team.md), техническая интеграция — [отдел автоматизации](../teams/automation-team.md).

## Связанные системы

Часть данных передаётся в [Bitrix24](bitrix24.md) каждые 15 минут. Сведения об учётной записи сопоставляются с [Active Directory](active-directory.md).

## Ограничения

Прямой доступ ограничен кадровыми ролями. Employee API предоставляет только утверждённое подмножество полей и не раскрывает зарплатные данные.

## Частые вопросы

**Где взять ФИО и подразделение?** В Employee API, который читает данные из 1С ЗУП.
