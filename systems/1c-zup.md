# 1С Зарплата и управление персоналом

{% note info %}

Демонстрационная кадровая система и единственный Source of Truth для сведений о сотруднике.

{% endnote %}

## Паспорт

| Факт | Ответ |
| --- | --- |
| Назначение | Ведение утверждённых кадровых данных и организационной структуры. |
| Основные данные | [Сотрудник](../data/employee.md): табельный ID, ФИО, должность, отдел, руководитель, статус. |
| Источник истины | Единственный Source of Truth для кадровых атрибутов сотрудника. |
| Бизнес-владелец | [HR-команда](../teams/hr-team.md) |
| Технический владелец | [Отдел автоматизации](../teams/automation-team.md) |
| Рекомендуемый доступ | [Employee API](../services/employee-api.md), а не прямая база или выгрузка. |

## Связи и поток данных

[Сотрудник](../data/employee.md) → **1С ЗУП** → [Employee API](../services/employee-api.md) → потребители кадровых данных.

Разрешённая часть профиля поступает в [Bitrix24](bitrix24.md) по [синхронизации](../integrations/zup-to-bitrix.md) каждые 15 минут. Учётные записи сопоставляются с [Active Directory](active-directory.md).

## Частые вопросы

**Где взять ФИО и подразделение?** В Employee API, который читает данные из 1С ЗУП.

{% cut "Доступ и ограничения" %}

Прямой доступ ограничен кадровыми ролями. Employee API предоставляет только утверждённое подмножество полей и не раскрывает зарплатные данные.

Не используйте прямое чтение базы 1С, выгрузки из интерфейса и копию в Bitrix24 как рабочий источник кадровых данных.

{% endcut %}

{% cut "Эксплуатация и связи" %}

Часть кадровых данных передаётся в Bitrix24 каждые 15 минут. При вопросах об интеграции обращайтесь к [отделу автоматизации](../teams/automation-team.md); правила данных определяет [HR-команда](../teams/hr-team.md).

{% endcut %}
