# Bitrix24

## Что это

Bitrix24 — демонстрационный корпоративный портал и CRM. В нём ведутся сделки, задачи и отображается справочная информация о сотрудниках.

## Для чего используется

Команда продаж ведёт в системе сделки и этапы воронки. Остальные сотрудники используют портал для задач и поиска коллег.

## Какие данные содержит

- [Сделка](../data/deal.md) — мастер-данные CRM.
- [Сотрудник](../data/employee.md) — ограниченная копия ФИО, подразделения, должности и руководителя.

## Source of Truth

Bitrix24 является Source of Truth для сделок. Для сотрудника, работника, начальника, отдела и кадрового статуса Bitrix24 **не является** источником истины: эти сведения приходят из [1С ЗУП](1c-zup.md).

## Как получить данные

Данные сотрудника следует получать через [Employee API](../services/employee-api.md), а не читать из Bitrix24. Доступ к данным CRM запрашивается по [общей инструкции](../guides/how-to-get-access.md); отдельный поддерживаемый API сделок в MVP не задокументирован.

## Владелец

Технический владелец — [отдел автоматизации](../teams/automation-team.md), бизнес-владелец CRM — [команда продаж](../teams/sales-team.md).

## Связанные системы

Кадровые сведения поступают из 1С ЗУП по [интеграции ЗУП → Bitrix24](../integrations/zup-to-bitrix.md). Учётные записи сопоставляются с [Active Directory](active-directory.md).

## Ограничения

Кадровая копия обновляется каждые 15 минут и может отставать от Source of Truth. В каталоге нет production URL, токенов и реальных учётных данных.

## Частые вопросы

**Где взять руководителя сотрудника?** Через Employee API, а не из Bitrix24.

**Где лежат данные о сделках?** Source of Truth для сделки — Bitrix24.
