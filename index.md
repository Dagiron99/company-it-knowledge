# IT Knowledge Catalog

## Не знаете, где взять данные?

Каталог помогает найти проверенный ответ без поиска по чатам и без догадок.

- [Данные](data/index.md) — что является Source of Truth и какие поля доступны.
- [Системы](systems/index.md) — что делает конкретная система и кто за неё отвечает.
- [Сервисы](services/index.md) — каким API пользоваться для получения данных.
- [Интеграции](integrations/index.md) — как связаны системы и что зависит от обмена.
- [Инструкции](guides/index.md) — как получить доступ или добавить знание.

## Как читать каталог

Каждая страница описывает одну сущность со стабильным ID. Связи между сущностями записаны в YAML front matter, а основной текст отвечает на реальные рабочие вопросы. Например: где получить руководителя сотрудника, кто отвечает за Employee API или откуда Bitrix24 получает организационную структуру.

{% note warning %}

Если информации нет в доверенной части каталога, она считается незадокументированной. Не следует достраивать ответ по косвенным признакам.

{% endnote %}

## Быстрый пример

Данные [«Сотрудник»](data/employee.md) имеют Source of Truth [1С ЗУП](systems/1c-zup.md), рекомендуемый доступ идёт через [Employee API](services/employee-api.md), а техническим владельцем является [отдел автоматизации](teams/automation-team.md).
