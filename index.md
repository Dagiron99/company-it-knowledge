## Карта ландшафта

### Кадровые данные

`Сотрудник` → [1С ЗУП](systems/1c-zup.md) → [Employee API](services/employee-api.md) → [Отдел автоматизации](teams/automation-team.md)

1С ЗУП — единственный Source of Truth для кадровых данных. Employee API — рекомендуемый способ их получить. [Bitrix24](systems/bitrix24.md) и [Active Directory](systems/active-directory.md) используют только отдельные копии атрибутов сотрудника.

### CRM и сделки

[Команда продаж](teams/sales-team.md) → [Bitrix24](systems/bitrix24.md) → `Сделка`

Bitrix24 — Source of Truth для [сделки](data/deal.md), но не для кадровых данных.

### Поток копии кадровых данных

[1С ЗУП](systems/1c-zup.md) → [синхронизация каждые 15 минут](integrations/zup-to-bitrix.md) → [Bitrix24](systems/bitrix24.md)

В портал передаётся только разрешённая часть профиля сотрудника. Изменять кадровые данные в Bitrix24 нельзя: следующая синхронизация перезапишет копию.
