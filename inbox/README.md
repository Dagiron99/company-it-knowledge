# Inbox: необработанная информация

Сюда временно помещаются старые Markdown-файлы, заметки, текст из Word, описания интеграций и материалы сотрудников, которые ещё не приведены к модели каталога.

{% note warning %}

Inbox **не является проверенным Source of Truth** и не попадает в AI index. Информация становится доверенной только после переноса в структурированную сущность, human review и merge в основной каталог.

{% endnote %}

## Workflow наполнения

```text
RAW INFORMATION
→ inbox
→ AI extraction
→ draft entities/changes
→ human review
→ Git merge
→ trusted knowledge catalog
```

Не помещайте сюда секреты, пароли, токены, production credentials или персональные документы. Дальнейшие действия описаны в [инструкции по внесению изменений](../guides/how-to-contribute.md).
